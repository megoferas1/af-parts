# AF Parts — نظام الجراش

ابلكيشن لكل اللي بيدخل ويخرج من جراش AF Fabworks:

- **السواقين وقطعهم:** كل سواق وعربياته، والقطع بالنوع والمقاس والكمية والحالة والمكان. دخول، خروج، جرد، وتركيب على العربية مع تسجيل القطعة القديمة اللي طلعت.
- **العدة:** عِدّة الجراش متقسمة بنفس أقسامها (مفاتيح، لقم، لحام، كهربا، زيوت، تجهيزات الموقع…)، من غير أكواد. فيها ليستتين جاهزتين: **عدة السباق** و**عدة التمرين**، وتقدر تعدّلهم أو تعمل ليستات جديدة.
- **التصدير:** المنتجات اللي بتتصنع، العملاء، الشحنات، والـ Packing List عربي وإنجليزي.
- **الطلعات:** سباق أو تمرين أو أي طلعة. تختار الليستة الجاهزة وتعلّم على اللي طالع معاك (أو "علّم الكل" للقسم كله). اللي مش متعلّم عليه مش بيطلع، وفي الرجوع بيظهرلك اللي طلع بس وتعلّم إنه اتحمّل في العربية. وكل حاجة بتتسجل رجعت سليمة أو تالفة أو اتركبت أو اتصرفت أو ضاعت.
- **QR (للقطع والمنتجات بس):** استيكرات فاضية تتطبع على ورق A4 (21 استيكر)، تلزق واحد على القطعة وتعمل سكان فيفتحلك التسجيل.
- **كشوفات PDF و Excel** بلوجو AF Fabworks والتاريخ، تتبعت على الواتس من زرار المشاركة.
- **السجل:** كل حركة باسم الموظف اللي عملها ووقتها.

## التشغيل (خطوة خطوة)

1. **Supabase:** اعمل مشروع جديد ← SQL Editor ← New query ← الصق محتوى `schema.sql` كله ← Run. وبعده بنفس الطريقة ملف العدة `update-tools.sql` (موجود في النسخة اللي عندك، مش على GitHub).
2. **حساب الأدمن:** Authentication ← Users ← Add user (إيميل + كلمة سر، وفعّل Auto Confirm).
   بعدها في SQL Editor شغّل السطر ده (بإيميلك):
   `insert into public.admins (user_id) select id from auth.users where email = 'YOUR-EMAIL@example.com';`
   وكمان: Authentication ← Sign In / Providers ← اقفل **Allow new users to sign up**.
3. **config.js:** من Project Settings ← API انسخ الـ Project URL والـ anon / publishable key وحطهم في `config.js`.
4. **GitHub:** ارفع كل الملفات في ريبو جديد (كلهم في فولدر واحد، مفيش فولدرات جوه) ← Settings ← Pages ← Deploy from branch (main / root).
5. **أول استخدام:** ادخل بحساب الأدمن ← الإعدادات (الترس) ← ضيف الموظفين بأرقامهم السرية، وراجع بيانات الشركة.

## ملاحظات
- الأرقام السرية للموظفين متشفّرة على السيرفر ومش بتظهر تاني (لو موظف نسي رقمه: الإعدادات ← اسمه ← رقم جديد).
- مسح الحاجات والتراجع عن الحركات للإدارة بس.
- لما تطبع الاستيكرات اختار **Actual size / 100%** مش "Fit to page".
- لو الاستيكر اتعمله سكان بكاميرا الموبايل العادية، هيفتح الابلكيشن على الحاجة على طول.
- لو التعديل مش ظاهر بعد رفع ملفات جديدة: اقفل الابلكيشن وافتحه تاني.
